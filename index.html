GoldSrc / Blender knownsWORKFLOW NOTES
1 · Bring an existing player into Blender

For inspection, SourceIO supports importing engine MDLs, including GoldSrc workflows documented by the Blender community. Its current format table lists MDL import, not MDL export.

SourceIO · importer ↗
2 · Keep an editable source pipeline

Decompile the target model into reference/animation SMDs and QC, edit the correct reference mesh and preserve its sequence set. Blender Source Tools handles SMD/QC interchange; choose a GoldSrc-compatible export setup.

Sven Co-op model replacement guide ↗Blender Source Tools ↗
3 · Classic GoldSrc rig constraints

Classic GoldSrc uses rigid vertex-to-bone assignment rather than smooth blended weights. The standard tutorial documents 128 bones and 4,080 triangles per SMD; verify limits against the exact compiler and target mod.

GoldSrc model export limits ↗
4 · Compiler / tooling choice

Use a GoldSrc-compatible studiomdl compiler, preferably the Sven Co-op build for Sven-specific features, and validate the compiled model in a viewer plus the game.

GoldSrc tool index ↗
Experimental: a newer Blender 5.2 GoldSrc MDL toolchain project advertises SMD/QC export and Sven StudioMDL compilation. Treat it as an emerging community project and validate its outputs before production use.
